## 相交链表

> 找到两个链表相交的位置，怎么找？想象一下两个链表加起来的节点和是相等的吧？如果我们用两个指针分别各走两个链表一次，相交的地方后面的节点个数是相等的，所以前面走的节点数也是相等的，这样就会相交

![image-20261022111444838](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20261022111444838.png)

就以这个链表来说：

p和q同时出发： p指针从A链出发，经过3次到达NULL

q指针从B链出发，经过2次到达NULL

这个过程两个指针都没有相交

然后p指针从B链出发，经过1次到达交点

然后q指针从A链出发，经过2次到达交点

p指针一共走了3+1=4次

q指针一共走了2+2=4次

两个指针就会在这个交点相遇

```Python
def getIntersectionNode(headA: ListNode, headB: ListNode) -> Optional[ListNode]:
    q ,p = headA,headB
    while p is not q:
        p = p.next if p else headA
        q = q.next if q else headB
    return q
```

## 反转链表

![image-20261022111459439](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20261022111459439.png)

> 反转链表：
>
> 首先我们需要遍历原链表所以需要一个指针一直来记录next来遍历原链表 next_node
>
> 还需要一个指针来记录上一个指针的位置 pre_node
>
> 还需要一个当前指针来操作链 cur_node

```Python
def reverseList(head: ListNode | None) -> ListNode | None:
    pre_node = None
    cur_node = head
    while cur_node:
        # 记录下一个指针，以防找不到原来的链表
        # 这个指针还不能提前定义，因为不排除cur_node is None 的情况
        next_node = head.next
        # 改链
        cur_node.next = pre_node
        # 记录下一个要指的节点
        pre_node = cur_node
        # 遍历
        cur_node = next_node
    # 结束条件是cur_node is None,所以改完的链表的头节点就是pre_node
    return cur_node
```

## 回文链表

![image-20261022150625638](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20261022150625638.png)

> 回文链表的思路就是用一个快慢指针找到整个链表的中点，然后将链表的后半部分反转，然后前后遍历链表，边遍历边比较

```Python
def isPalindrome(self, head: Optional[ListNode]) -> bool:
    s = f = head
    # 快慢指针遍历
    while f and f.next:
        f = f.next.next
        s = s.next
    #取到链表的后半部分
    cur = s
    #定义pre指针准备把后部分反转
    pre = None
    #开始反转
    while cur:
        next_node = cur.next
        cur.next = pre
        pre = cur
        cur = next_node
    #反转完成开始遍历比较
    l = head
    r = pre
    while r:
        if l.val != r.val:
            return False
        l = l.next
        r = r.next
    return True
```
