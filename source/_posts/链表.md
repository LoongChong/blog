## 相交链表

> 找到两个链表相交的位置，怎么找？想象一下两个链表加起来的节点和是相等的吧？如果我们用两个指针分别各走两个链表一次，相交的地方后面的节点个数是相等的，所以前面走的节点数也是相等的，这样就会相交

![image-20261022111444838](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20261022111444838.png)

就以这个链表来说：

p和q同时出发： p指针从A链出发，经过3次到达NULL

q指针从B链出发，经过2次到达NULL

这个过程两个指针都没有相交

然后p指针从B链出发，经过1次到达交点

然后q指针从A链出发，经过2次到达交点

p指针一共走了3+1=4次

q指针一共走了2+2=4次

两个指针就会在这个交点相遇

```Python
def getIntersectionNode(headA: ListNode, headB: ListNode) -> Optional[ListNode]:
    q ,p = headA,headB
    while p is not q:
        p = p.next if p else headA
        q = q.next if q else headB
    return q
```

## 反转链表

![image-20261022111459439](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20261022111459439.png)

> 反转链表：
>
> 首先我们需要遍历原链表所以需要一个指针一直来记录next来遍历原链表 next_node
>
> 还需要一个指针来记录上一个指针的位置 pre_node
>
> 还需要一个当前指针来操作链 cur_node

```Python
def reverseList(head: ListNode | None) -> ListNode | None:
    pre_node = None
    cur_node = head
    while cur_node:
        # 记录下一个指针，以防找不到原来的链表
        # 这个指针还不能提前定义，因为不排除cur_node is None 的情况
        next_node = head.next
        # 改链
        cur_node.next = pre_node
        # 记录下一个要指的节点
        pre_node = cur_node
        # 遍历
        cur_node = next_node
    # 结束条件是cur_node is None,所以改完的链表的头节点就是pre_node
    return cur_node
```

## 回文链表

![image-20261022150625638](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20261022150625638.png)

> 回文链表的思路就是用一个快慢指针找到整个链表的中点，然后将链表的后半部分反转，然后前后遍历链表，边遍历边比较

```Python
def isPalindrome(self, head: Optional[ListNode]) -> bool:
    s = f = head
    # 快慢指针遍历
    while f and f.next:
        f = f.next.next
        s = s.next
    #取到链表的后半部分
    cur = s
    #定义pre指针准备把后部分反转
    pre = None
    #开始反转
    while cur:
        next_node = cur.next
        cur.next = pre
        pre = cur
        cur = next_node
    #反转完成开始遍历比较
    l = head
    r = pre
    while r:
        if l.val != r.val:
            return False
        l = l.next
        r = r.next
    return True
```

## 环形链表

![image-20261023154922552](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20261023154922552.png)

判断一个链表中是否有环：我们可以使用两个指针，快慢指针来遍历链表，判断两个指针是否会相遇，我们称这个方法为**快慢指针套圈法**

```Python
def isCycle(head):
    fast = slow = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if fast == slow:
            return True
    return False
```

如果我们需要返回链表入环的第一个节点，我们使用**Floyd判圈法：**

![image-20261023154936919](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20261023154936919.png)

假设相遇的时候slow走了 **B步** ，则快指针走了 **2B步** ，假设快指针比慢指针多走了 **k圈** ，所以我们得到：

**2B - B =** **kc**  **,  得 B = kc**

慢指针从入环口开始，走了 **B - A步 = kc - A 步。**

所以满指针 kc - A + A = kc , 所以慢指针**再走A步**就达到入环口了，我们就可以定义一个指针在head，同时和慢指针跑，直到他们两个人相遇，相遇的地方就是入环点

```Python
def findCycle(head):
    fast = slow = head
    while fast and fast.next:
        fast = fast.next.next
        slow = slow.next
        if fast == slow:
            while slow != head:
                slow = slow.next
                head = head.next
            return head
    return None
```

## 合并链表

![image-20261023154951634](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20261023154951634.png)

首先我们需要定义一个dummy节点来作为连接两个链表的开端，因为由他决定两个链表的第一个节点是谁？

dummy.next 就是第一个节点

P 和 q 两个指针用来遍历两个链表比较大小

```Python
def mergeChians(list1,list2):
    Dummy = ListNode(-1)
    p = list1
    q = list2
    cur = Dummy
    while p and q:
        if p.val <= q.val:
            cur.next = p
            p = p.next
        else:
            cur.next = q
            q = q.next
        cur = cur.next
    # 如果一个链表跑完了另一个没有完，直接连上它
    cur.next = p or q
    return Dummy.next   
```

## 删除链表的节点

给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

![image-20261023155005355](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20261023155005355.png)

使用快慢指针，让快指针先走n步，然后快慢指针一起走，最后慢指针指向的就是倒数第N个节点

```Python
def removeNode(head,n):
    # 因为有可能删除的是第一个节点，我们就需要一个哨兵节点
    dummy = ListNode(-1,head)
    fast = slow = dummy
    for _ in range(n):
        fast = fast.next
    while fast.next:
        fast = fast.next
        slow = slow.next
    slow.next = slow.next.next
    return dummy.next
```

## 交换链表中的节点

def swapPairs(head):
    dummyHead = ListNode(0)
    dummyHead.next = head
    temp = dummyHead
    while temp.next and temp.next.next:
        node1 = temp.next
        node2 = temp.next.next
        temp.next = node2
        node1.next = node2.next
        node2.next = node1
        temp = node1
    return dummyHead.next
