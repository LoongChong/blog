## 爬楼梯

思路：爬楼梯可以分两个思路，自下向上和自上向下

自下向上：迭代法，找规律

自上向下：递归法，然后避免子问题的重复计算，加一个缓存字典来减少性能消耗

### 迭代法

首先先用暴力枚举的方法来找规律 如果有一个台阶，只有一种方法，如果有两个台阶，有两种方法。如果有三个台阶，就有多少种方法，我们发现第三个台阶不就是从第一个台阶和第二个台阶走上来的嘛？所以第三个台阶就是第一个加第二个的和，后面类似迭代。

```Python
def deidai(n):
```

### 递归法

递归的方法就是拆解问题的子问题

爬到第n阶台阶前，可以从n-1或者从n-2上跳上去所以得出：

**f(n) = f(n-1) + f(n-2)**

然后我们需要优化的点就是需要把子问题进行缓存，从而减少递归的性能开销我们可以创建一个字典缓存,如果我们计算过这个子问题，我们直接返回他的值

```Python
def digui(n):

```

## 打家劫舍

打家劫舍同样的道理，我们分析一下

| x    | 2    | 7    | 9    | 3    | 1    | 5    | 8    |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| F(x) | 2    | 7    | 11   | 11   | 12   | 16   | 20   |

我们对比的是啥？就是f(x-2) + x 和 f(x-1)的大小

### 迭代法

```Python
def rob(nums):
    if not nums:
        return 0
    if len(nums)==1:
        return nums[0]
    prev1 = nums[0]
    prev2 = max(nums[0],nums[1])
    for i in range(2,len(nums)):
        curr = max(nums[i]+prev1,prev2)
        prev1 = prev2
        prev2 = curr
    return prev2
```

### 递归法

```Python
def rob(nums):
    memo = {}
    def dfs(n):
        if n < 0:
            return 0
        if n in memo:
            return memo[n]
        result = max(dfs(n-2)+nums[n],dfs(n-1))
        memo[n] = result
        return result
    return dfs(len(nums)-1)
```
