# 0/1背包

## 递归法

我们使用dp[i][w]二维数组来表示前i个物品的最大价值

val[i]表示第i个物品的价值，weight[i]表示第i个物品的重量

递归法就是我们从最大价值的开始分析选不选：

如果选的价值：val[i] + dp[ i-1 ][ w-weight [i] ]

如果没有选的价值： dp[ i - 1 ][ w ]

```Python
def knappack(wt,val,cap,index):
    if index == len(wt):
        return 0
    no_pick = knappack(wt,val,cap,index+1)
    pick = 0
    if wt[index] <= cap:
        pick = val[index] + knappack(wt,val,cap-wt[index],index+1)
        
    return max(no_pick, pick)
```

**记忆化搜索：使用一个dp****二维数组****来保存计算过的数据，防止多次计算重复的子问题**

```Python
def knappack(wt,val,cap):
    n = len(wt)
    dp = [[-1 for _ in range(cap + 1)] for _ in range(n)]
    def helper(index, remaining_cap):
        if index == n:
            return 0
        if dp[index][remaining_cap] != -1:
            return dp[index][remaining_cap]
        not_pick = helper(index + 1, remaining_cap)
        pick = 0
        if wt[index] <= remaining_cap:
            pick = val[index] + helper(index + 1, remaining_cap - wt[index])
        dp[index][remaining_cap] = max(pick, not_pick)
        return dp[index][remaining_cap]
    return helper(0, cap)
```

## 表格法

```Python
def knapsack_dp(wt, val, cap):
    n = len(wt)
    dp = [[0] * (cap + 1) for _ in range(n)]
    # 先处理第0行，只考虑第一个物品
    for w in range(wt[0], cap + 1):
        dp[0][w] = val[0]
    # 填充剩余行
    for i in range(1, n):
        for w in range(cap + 1):
            not_pick = dp[i-1][w]
            pick = 0
            if wt[i] <= w:
                pick = val[i] + dp[i-1][w-wt[i]]
            dp[i][w] = max(pick, not_pick)
    return dp[n-1][cap]
```
