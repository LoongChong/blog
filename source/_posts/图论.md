## 图的基本定义

图分 无向图和有向图

连通图：指的是无向图中的每个节点都可以通过一条或者多条路径互相到达

强连通图：指的是有向图中每个节点可以通过一条或多条路径互相到达

连通分量：指的是无向图中节点数最大的那个连通图

强连通分量：指的是有向图中节点数最大的那个强连通图

## 岛屿问题

```Python
def numIslands(grid):
    # 首先计算岛屿的大小确定边界值
    n, m = len(grid), len(grid[0])
    # dfs深度搜索
    def dfs(i,j):
        # 首先确定终止条件
        if i < 0 or i >= n or j < 0 or j >= m:
            return
        if grid[i][j] != '1':
            return
        # 做标记    
        grid[i][j] = '2'
        # 递归四个方向
        dfs(i,j-1)
        dfs(i,j+1)
        dfs(i-1,j)
        dfs(i+1,j)
    res = 0
    # 然后遍历岛屿
    for i in range(n):
        for j in range(m):
            #判断此时的块是不是陆地
            if grid[i][j] == '1':
                dfs(i,j)
                res += 1
    return res
```

## 腐烂的橘子

```Python
def orangesRotting(grid):
    n, m = len(grid), len(grid[0])
    # 广度优先搜索，先定义一个队列q
    q = []
    fresh = 0
    # 还是先遍历图，先将所有的坏橘子入队
    for i ,row in enumerate(grid):
        for j, col in enumerate(row):
            if col == 2:
                q.append((i, j))
            if col == 1:
                fresh += 1
    res = 0
    while q and fresh:
        # 定义一个tmp来存这一轮的坏橘子，q清空来存下一轮的
        res += 1
        tmp = q
        q = []
        for x, y in tmp:
            for i, j in (x - 1, y), (x + 1, y), (x, y - 1), (x, y + 1):  # 四方向
                if 0 <= i < n and 0 <= j < m and grid[i][j] == 1: 
                    fresh -= 1
                    grid[i][j] = 2
                    q.append((i, j))
    return -1 if fresh else res
```
