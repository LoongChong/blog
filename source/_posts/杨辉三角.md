## 杨辉三角

```Python
def generate(self, numRows: int) -> list[list[int]]:
        # 首先创建一个杨辉三角形的结构，把值都赋值为1
        c = [[1]*(i+1) for i in range(numRows)]
        # 然后再依次更新每个值
        # 观看整个三角形的结构：
        # [1]
        # [1,1]
        # [1,2,1]
        # [1,3,3,1]
        # [1,4,6,4,1]
        # 我们发现规律：
        # 除了第一个元素和最后一个元素，其余的元素都等于左上角和正上方的和
        # 然后我们定义边界：第一行和第二行的元素不需要管，所以是range(2,numRows)
        #                 每一行的第一个元素和最后一个元素不用管，所以是range(1,i)
        for i in range(2, numRows):
            for j in range(1,i):
                c[i][j] = c[i-1][j-1] + c[i-1][j]
        return c
```
